# 👗 LesChic: The Art of Dressing

A luxury full-stack closet management ecosystem featuring a high-end web experience and a companion mobile application. LesChic allows users to digitize their wardrobe, manage clothing items with detailed metadata, and filter their collection through a cinematic, interactive interface.

## ✨ Features
* **Cinematic Web Interface** — A "luxury-first" design featuring GSAP-powered keyhole reveals and smooth scroll animations.
* **Mobile Companion** — A fully functional Flutter app for managing your closet on the go.
* **Smart Filtering** — Advanced multi-parameter filtering by Category, Brand, Tags, and Color Palettes (supporting slash-combined options like TAN/WHITE).
* **Dynamic Closet Management** — Full CRUD functionality with animated modals for adding and editing clothing details.
* **Secure Authentication** — JWT-based authentication with protected routes and persistent user sessions.
* **Asset Management** — Cloud-stored imagery for every clothing item, optimized for both web and mobile viewing.
